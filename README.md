# Study Agent Demo

## Overview
Study Agent Demo is a study agent assistant developed with Python and Deepseek API.
The project is being continuously maintained and developed as a personal software project.

## Features
- multi-turn conversations
- context-aware interactions
- function calling with custom tools
- LLM can select and execute tools based on user requests 
- agent execution loop to process tool calls
- feed back tool results
- JSON-based conversation memory
- basic error handling
